# Kenny Studio / Prism redesign

Scope: public website, customer account/order portal and owner workspace, explicitly confirmed by the owner. All three visual references inform one identity: violet/chrome cinematic hero, a floating glass navigation capsule, oversized type with italic accents, an orbital card scene, scroll-linked perspective, video and restrained workspace motion.

Preserved: I'M KENNY and the original Pc introduction video/player; index film gallery; About/profile; all portfolio projects and links; services; published package scopes/prices; project process; global coverage and contact; the real persisted enquiry form with verified noindex thank-you; customer authentication; billing/payment verification; owner income/inquiry/task/export tools; new-order alerts; WhatsApp/Facebook/TikTok controls; existing logos/favicons and role separation.

The original intro player is passed into the new experience section with the original language/sound/suspension props; its controls remain. The chrome hero uses an original generated illustration and an eight-second H.264 living-poster loop, not a remote video service. Videos are muted, motion is paused offscreen/when hidden, and reduced-motion/save-data preferences are respected. The customer login background uses the same small, self-hosted video. The owner interface adopts the same palette while retaining readable tables, semantic payment badges and clear focus styles.

Public entry pages: home, services and each service detail, pricing, policy, privacy, thank-you, 404, and existing cart/order redirects. The new bundle changes the original hero and adds an experience section; all remaining sections and real enquiry logic are retained. Client and owner templates load the final scoped stylesheet after their previous styles, keeping their scripts/data paths independent.

Validation: backend suite, customer account/modal/hub flows, persisted enquiry/thank-you and conversion-dedup tests, income, owner tables/live sync/order bell, plus explicit Prism content/CTA/media/SEO preservation and motion visibility/pause/reduced-motion/observer tests. Chromium cannot launch in the execution sandbox, so no real browser screenshot or visual end-to-end test is claimed. Preview markup and reference contact sheets are in /workspace/work/prism-release and /workspace/work/new-site-reference.

No Stripe mode/key changes, actual charges, data migrations or new external tracking code are part of this redesign. Google Ads conversion ID/label remain unprovided from the previous task.


Client feedback: the owner does not yet have real testimonials. The live empty-data state uses four factual service advantages (clear scope, stage payments, client project visibility and direct communication), plus a feedback-sharing link. No customer names, quotes, star ratings or review counts are fabricated. The review-ready JSON file remains empty until genuine content is supplied.
